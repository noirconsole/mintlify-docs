## How Proxies Work

Noir Console supports proxies in every module. You don't need to assign a proxy to each individual account in Token Manager — instead, **you set proxies directly in the module you're working with**.

Each module (SMM, Quoting, Scraping, Posting Tool, etc.) has its own proxy input field where you can paste proxies for that specific operation.

### Per-Account Proxies

There are only two sections where proxies are tied to individual accounts:
- **DM** — each DM sender account has its own proxy
- **Warmer** — each warmer account has its own proxy

This is because DM sending and account warming are long-running operations where each account needs a persistent, unique connection.

## Proxy Types

| Type | Speed | Anonymity | Best For |
|------|-------|-----------|----------|
| **Residential** | Medium | High | DM sending, following, long-term accounts |
| **ISP/Static** | Fast | High | Main accounts, posting, long sessions |
| **Datacenter** | Fast | Medium | Bulk operations, scraping |
| **Mobile** | Varies | Very High | High-value accounts, anti-detection |

<Tip>
  **Residential or ISP proxies** are the safest choice for most use cases. Datacenter proxies are cheaper but more likely to be flagged.
</Tip>

## Proxy Formats

Noir Console supports these formats:

```
http://ip:port
http://username:password@ip:port
socks5://ip:port
socks5://username:password@ip:port
```
