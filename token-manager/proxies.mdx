## Why Proxies Matter

<Warning>
  **This is critical.** Running multiple X accounts from the same IP address is the #1 reason accounts get banned. Proxies are not optional — they are essential for any serious operation.
</Warning>

When you run multiple accounts without proxies, X sees all of them coming from the same IP. This is a clear signal of automation, and X will ban or restrict those accounts.

**Proxies give each account (or group of accounts) a unique IP address**, making activity look natural.

## Proxy Types

| Type | Speed | Anonymity | Best For |
|------|-------|-----------|----------|
| **Residential** | Medium | High | DM sending, following, long-term accounts |
| **ISP/Static** | Fast | High | Main accounts, posting, long sessions |
| **Datacenter** | Fast | Medium | Bulk operations, scraping |
| **Mobile** | Varies | Very High | High-value accounts, anti-detection |

<Tip>
  **Residential or ISP proxies** are the safest choice for most use cases. Datacenter proxies are cheaper but more likely to be flagged.
</Tip>

## Proxy Formats

Noir Console supports these proxy formats:

```
http://ip:port
http://username:password@ip:port
socks5://ip:port
socks5://username:password@ip:port
```

## How to Assign Proxies

Proxies are assigned in the **Token Manager Pool**:

1. **During import** — paste tokens with proxies: `auth_token:proxy` or `auth_token|proxy`
2. **Per account** — edit proxy directly in the pool table

## Best Practices

<AccordionGroup>
  <Accordion title="One proxy per 1-3 accounts">
    Don't overload a single proxy with too many accounts. Spread your accounts across multiple proxy IPs.
  </Accordion>
  <Accordion title="Use residential for DMs and follows">
    DM sending and following are the most sensitive actions. Use residential or mobile proxies for these.
  </Accordion>
  <Accordion title="Test proxies before campaigns">
    Make sure your proxies are working before starting a campaign. A dead proxy means failed operations and wasted time.
  </Accordion>
  <Accordion title="Rotate proxies periodically">
    If you notice accounts getting restricted, try rotating to fresh proxy IPs.
  </Accordion>
</AccordionGroup>
