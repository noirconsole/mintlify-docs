## How Proxies Work

Noir Console supports proxies in every module. You don't need to assign a proxy to each individual account in Token Manager — instead, **you set proxies directly in the module you're working with**.

Each module (SMM, Quoting, Scraping, Posting Tool, etc.) has its own proxy input field where you can paste proxies for that specific operation.

### Per-Account Proxies

There are only two sections where proxies are tied to individual accounts:
- **DM** — each DM sender account has its own proxy
- **Warmer** — each warmer account has its own proxy

This is because DM sending and account warming are long-running operations where each account needs a persistent, unique connection.

## Our Recommendations

<Warning>
  Using accounts without proxies **will get them banned**. Always use proxies.
</Warning>

### Static (ISP) Proxies — for DM and Warmer

For **DM sending** and **Warmer**, we recommend **static (ISP) proxies**. These modules run long sessions on the same account — the connection needs to stay stable and look like a real user sitting at one IP address.

- One static proxy per account
- The IP doesn't change — X sees a consistent connection
- Best providers: any ISP/static residential proxy service

### Residential or Mobile Proxies — for mass operations

For **Quoting**, **SMM**, **Scraping**, **Posting Tool**, and other bulk modes, we recommend **residential** or **mobile** proxies. These modules cycle through many accounts quickly — rotating IPs look more natural for this pattern.

- Residential proxies rotate IPs automatically — each request can come from a different address
- Mobile proxies are the safest option (mobile carrier IPs are rarely flagged by X)
- Best for: any mode where many accounts perform actions in a short burst

### Summary

| Module | Recommended Proxy Type | Why |
|--------|----------------------|-----|
| **DM** | Static / ISP | Long sessions, one account per IP |
| **Warmer** | Static / ISP | Persistent warming, stable connection |
| **Quoting** | Residential / Mobile | Burst of actions from many accounts |
| **SMM** | Residential / Mobile | Mass likes, RT, follows across accounts |
| **Scraping** | Residential / Mobile | High request volume, IP rotation needed |
| **Posting Tool** | Residential / Mobile | Posting + boost from many accounts |

## Proxy Formats

Noir Console supports these formats:

```
http://ip:port
http://username:password@ip:port
socks5://ip:port
socks5://username:password@ip:port
```
