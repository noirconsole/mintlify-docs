## Overview

Token Manager is the central hub for all your X (Twitter) accounts. Every other module in Noir Console depends on it — you need to load accounts here before you can post, send DMs, boost, or do anything else.

<Warning>
  **This is the first thing you should set up.** No module will work without accounts loaded into Token Manager.
</Warning>

### How accounts work

Noir Console uses **auth_tokens** to authenticate with X. An auth_token is a cookie value that represents an active session on X.

<Steps>
  <Step title="Get your auth_tokens">
    Extract auth_tokens from your X accounts. Each token is a long string that looks like a random hash.
  </Step>
  <Step title="Load into Pool">
    Paste your tokens into the Token Manager Pool — one token per line.
  </Step>
  <Step title="Validate">
    Run validation to check which tokens are still active. Invalid tokens are marked automatically.
  </Step>
  <Step title="Create groups">
    Organize valid accounts into groups for use in other modules (DM, SMM, Quoting, etc.).
  </Step>
</Steps>
