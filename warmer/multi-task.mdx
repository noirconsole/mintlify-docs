## Multi-Task

The Warmer supports running multiple warming tasks at the same time. Each task can target different account groups with different parameters.

<Frame>
  <img src="/images/warmer-tasks.png" alt="Warmer multi-task view" />
</Frame>

### Task Cards

Each warming task appears as a card on the dashboard showing:
- **Task name** — identifies the task
- **Account count** — how many accounts are being warmed
- **Status** — running, paused, or completed
- **Progress** — current warming progress

### Managing Tasks

- **Create** — start a new warming task
- **Edit** — modify task parameters
- **Pause/Resume** — temporarily stop or continue a task
- **Delete** — remove a completed or unwanted task

<Info>
  Tasks persist across restarts. If the server restarts, warming tasks resume automatically.
</Info>
