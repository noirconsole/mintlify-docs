### How to Use

<Steps>
  <Step title="Select warmer accounts">
    Go to **Warmer → Accounts** to set up which accounts will be used for warming operations.
  </Step>
  <Step title="Configure warming task">
    On the Dashboard, create a new warming task:
    - Select the accounts to warm
    - Set activity parameters
  </Step>
  <Step title="Start">
    Launch the warming task. Accounts begin performing natural-looking activity.
  </Step>
  <Step title="Monitor">
    Track progress on the dashboard — see which accounts are active and their warming status.
  </Step>
</Steps>

### What the Warmer Does

The warmer performs natural activity patterns:
- Browsing timelines
- Liking tweets
- Light interactions

This builds up account activity history, making them look like real users to X's algorithms.

<Tip>
  Warm new accounts for at least a few days before using them for campaigns. The longer the warm-up period, the safer the accounts.
</Tip>
