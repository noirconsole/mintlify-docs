## Quote Tags

Quote Tags lets your accounts quote-tweet a target tweet and **include @mentions** of target users in the quote text. Each mentioned user gets a notification, driving them to view the quoted tweet.

  <img src="/images/quote-tags.png" alt="Quote Tags page" />
</Frame>

### How to Use

<Steps>
  <Step title="Select token group">
    Choose accounts that will create the quote tweets.
  </Step>
  <Step title="Enter tweet URL">
    Paste the URL of the tweet you want to quote.
  </Step>
  <Step title="Upload usernames to tag">
    Upload a file with target usernames. These will be @mentioned in the quote tweets.
  </Step>
  <Step title="Add text (optional)">
    Add custom text for the quote tweet. The @mentions are added automatically from your uploaded list.
  </Step>
  <Step title="Set tag count">
    Choose how many users to @mention per quote tweet.
  </Step>
  <Step title="Start">
    Click **Start**. Each account creates a quote tweet with @mentions from the list.
  </Step>
</Steps>

### Results

Track progress via the live counter — successful quotes, failed attempts, and total.

<Info>
  Quote tweets create new tweets on each account's timeline, linking back to the original. Each mentioned user gets a notification, giving the original tweet more visibility.
</Info>
