## Quote Tags

Quote Tags lets your accounts quote-tweet a target tweet, optionally tagging other users in the quote. This amplifies the reach of the original tweet by spreading it across multiple timelines.

<Frame>
  <img src="/images/quote-tags.png" alt="Quote Tags page" />
</Frame>

### How to Use

<Steps>
  <Step title="Select token group">
    Choose accounts that will create the quote tweets.
  </Step>
  <Step title="Enter tweet URL">
    Paste the URL of the tweet you want to quote.
  </Step>
  <Step title="Add text and tags (optional)">
    Add custom text for the quote tweet. Optionally include @usernames to tag.
  </Step>
  <Step title="Start">
    Click **Start**. Each account in the group creates a quote tweet.
  </Step>
</Steps>

### Results

Track progress via the live counter — successful quotes, failed attempts, and total.

<Info>
  Quote tweets create new tweets on each account's timeline, linking back to the original. This gives the original tweet more visibility in X's algorithm.
</Info>
