## Overview

The Quoting module offers multiple engagement modes — all designed to increase visibility and drive engagement to tweets. Each mode works differently and serves a different purpose.

<CardGroup cols={2}>
  <Card title="Image Tags" icon="image" href="/quoting/quote-tags">
    Tag users in image tweets for notification-based outreach.
  </Card>
  <Card title="Quote Tags" icon="quote-left" href="/quoting/quote-tags">
    Quote tweet with tags to amplify reach.
  </Card>
  <Card title="Reply Quotes" icon="reply" href="/quoting/reply-quotes">
    Reply to tweets with @mentions and custom text.
  </Card>
  <Card title="Wall Posts" icon="clone" href="/quoting/wall-posts">
    Post the same message across multiple accounts' timelines.
  </Card>
</CardGroup>

### When to Use Each Mode

| Mode | Best For |
|------|----------|
| **Image Tags** | Getting attention via image tag notifications |
| **Quote Tags** | Amplifying a tweet by quoting it from many accounts |
| **Reply Quotes** | Engaging in tweet conversations with mentions |
| **Wall Posts** | Broadcasting a message across many account timelines |
