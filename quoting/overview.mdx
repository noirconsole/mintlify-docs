## Overview

The Quoting module offers multiple engagement modes — all designed to increase visibility and drive engagement to tweets or accounts.

<CardGroup cols={2}>
  <Card title="Image Tags" icon="image" href="/quoting/image-tags">
    Tag users in image tweets for notification-based outreach.
  </Card>
  <Card title="Quote Tags" icon="quote" href="/quoting/quote-tags">
    Quote tweet with tags to amplify reach.
  </Card>
  <Card title="Reply Quotes" icon="reply" href="/quoting/reply-quotes">
    Reply to tweets with @mentions and custom text.
  </Card>
  <Card title="Wall Posts" icon="clone" href="/quoting/wall-posts">
    Post the same message across multiple accounts' timelines.
  </Card>
</CardGroup>

### When to Use Each Mode

| Mode | What it does | Input format |
|------|-------------|-------------|
| **Image Tags** | Posts an image and tags users in it — they get a notification | User IDs (directly from scraper) |
| **Quote Tags** | Quote-tweets a target tweet from multiple accounts with @mentions | Usernames (resolver needed) |
| **Reply Quotes** | Posts replies under a tweet with @mentions | Usernames (resolver needed) |
| **Wall Posts** | Posts text on multiple accounts' timelines | Usernames (resolver needed) |
