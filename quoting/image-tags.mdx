## Image Tags

Image Tags is a powerful outreach method — your accounts post a tweet with an image, and **tag target users in that image**. Each tagged user receives a notification, driving them to see your content.

<Frame>
  <img src="/images/image-tags.png" alt="Image Tags page" />
</Frame>

### How It Works

When you tag someone in an image on X, they get a notification: "You were tagged in a photo." This is a direct way to put your content in front of target users.

### How to Use

<Steps>
  <Step title="Select token group">
    Choose which accounts will post the image tweets.
  </Step>
  <Step title="Upload image">
    Upload the image that will be posted.
  </Step>
  <Step title="Add tweet text">
    Write the text that accompanies the image.
  </Step>
  <Step title="Load target user IDs">
    Upload user IDs (directly from the Scraper — no resolver needed for this mode).
  </Step>
  <Step title="Start">
    Click **Start**. Each account posts the image and tags a batch of users in it.
  </Step>
</Steps>

<Info>
  Image Tags accepts **user IDs directly** from the scraper output. You don't need to resolve them to usernames first — this is one of only two modes (along with Bulk DM) that works with raw IDs.
</Info>

### Tips

- Use eye-catching images that make users want to click through
- Keep the tweet text relevant to your target audience
- Don't overuse — tagging too aggressively can lead to reports
