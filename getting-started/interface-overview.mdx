## Main Layout

The Noir Console interface consists of three main areas:

  <img src="/images/interface-overview.png" alt="Noir Console interface overview" />
</Frame>

### Sidebar (Left)

The sidebar is your main navigation. It contains all modules organized by function:

| Module | What it does |
|--------|-------------|
| **DexScreener** | Monitor new token listings and trending tokens |
| **Scraping** | Scrape followers, community members, resolve usernames |
| **Token Manager** | Manage accounts, groups, unlock, change profiles |
| **DM** | Direct message outreach — accounts, targets, templates, bulk send |
| **List** | Track X lists in real-time |
| **SMM** | Likes, retweets, follows, follow-for-follow raids |
| **Quoting** | Quote tweets, reply quotes, wall posts, image tags |
| **Posting** | Post & boost from main account |
| **Warmer** | Warm up accounts with natural activity |

Click any module to expand its sub-pages. The colored dot next to each module name helps you quickly identify sections.

At the top of the sidebar you'll see:
- **Noir logo** and app version
- **Backend status indicator** — green dot means the server is running

### Header (Top)

The header bar contains:

- **Breadcrumbs** — shows your current location (e.g., "Token Manager / Pool")
- **Language toggle** — switch between English and Russian
- **Theme toggle** — switch between dark and light mode
- **Live Logs** — toggle the real-time log panel
- **Start / Stop** — start or stop all background services

### Content Area (Center)

The main area where each module's interface is displayed. Most pages include:
- Action buttons at the top
- Data tables or card layouts
- Status indicators and counters

## Command Palette

Press <Tooltip tip="Cmd+K on macOS, Ctrl+K on Windows">**⌘K**</Tooltip> to open the command palette — a quick search that lets you jump to any page instantly.

## Live Logs Panel

Click the **panel icon** in the header to open the live logs rail on the right side. This shows real-time output from all running services. You can:
- Filter logs by module
- Pause/resume the log stream
- Clear the log history

<Info>
  Live logs are useful for monitoring bulk operations like DM sending, account validation, or scraping progress.
</Info>

## Theme

Noir Console supports dark and light themes. Click the **sun/moon icon** in the header to toggle. Your preference is saved automatically.

## Language

Switch between **English** and **Russian** using the flag buttons in the header. The entire interface is translated.
