## Auto Mode

Auto Mode runs engagement campaigns automatically in the background. Unlike manual raids, you configure the parameters once and let it run.

<Frame>
  <img src="/images/smm-auto.png" alt="SMM Auto Mode page" />
</Frame>

### How to Use

<Steps>
  <Step title="Select token group">
    Choose the accounts that will perform the actions.
  </Step>
  <Step title="Configure targets">
    Set up which tweets or accounts to engage with.
  </Step>
  <Step title="Set parameters">
    Configure engagement type (likes, retweets), intervals, and limits.
  </Step>
  <Step title="Start">
    Click **Start** and the campaign runs in the background.
  </Step>
</Steps>

### Monitoring

Track progress through:
- Live counters on the page
- **Live Logs** panel for detailed per-account activity

<Tip>
  Auto mode is best for sustained engagement campaigns. For one-time bursts, use Raids instead.
</Tip>
