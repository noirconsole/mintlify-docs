## Boost Groups

Boost groups are token groups from Token Manager that automatically engage with your posts after publishing. When you post from your main account, the boost group accounts like and retweet it immediately.

### Setting Up Boost Groups

<Steps>
  <Step title="Create a group in Token Manager">
    Go to Token Manager → Groups and create a group with accounts dedicated to boosting.
  </Step>
  <Step title="Select in Posting Tool">
    When creating a post, select this group as the boost group.
  </Step>
</Steps>

### Best Practices

<AccordionGroup>
  <Accordion title="Use dedicated boost accounts">
    Keep a separate group specifically for boosting — don't mix these with DM or follow accounts.
  </Accordion>
  <Accordion title="Size matters">
    More accounts in the boost group = more initial engagement = better algorithmic ranking.
  </Accordion>
  <Accordion title="Assign proxies">
    Boost accounts need proxies too — many accounts liking from the same IP looks suspicious.
  </Accordion>
</AccordionGroup>
