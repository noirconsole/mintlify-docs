## Task Management

The Posting Tool supports persistent tasks — your posting operations survive server restarts and can be managed independently.

<Frame>
  <img src="/images/posting-tasks.png" alt="Posting Tool task management" />
</Frame>

### Task Lifecycle

Each post creates a task that goes through these states:

| State | Meaning |
|-------|---------|
| **Running** | Post published, boost in progress |
| **Paused** | Task paused — can be resumed |
| **Completed** | All boost actions finished |
| **Failed** | Post or boost failed |

### Managing Tasks

- **Pause** — temporarily stop a boost operation
- **Resume** — continue a paused task
- **Stop** — cancel the task entirely

<Info>
  Tasks persist across server restarts. If the server goes down and comes back up, your tasks resume automatically from where they left off.
</Info>
