## Universal Scraper

The Universal Scraper works with **any X URL**. Just paste the right link and it will scrape all users from that page — retweeters, quoters, commenters, search results, list members, and more.

<Frame>
  <img src="/images/universal-scraper.png" alt="Universal Scraper page" />
</Frame>

### How to Use

<Steps>
  <Step title="Select token group">
    Choose a group from Token Manager for scraping.
  </Step>
  <Step title="Paste URLs">
    Enter one or more X URLs. The scraper detects what's on the page and collects all users.
  </Step>
  <Step title="Start">
    Click **Start** to begin scraping.
  </Step>
  <Step title="Download">
    Download the results as a `.txt` file.
  </Step>
</Steps>

### URL Examples

The key is using the right URL for what you want to scrape:

| URL format | What it scrapes |
|------------|----------------|
| `x.com/username` | Account's followers |
| `x.com/username/status/123456` | Users who **commented** on the tweet |
| `x.com/username/status/123456/retweets` | Users who **retweeted** |
| `x.com/username/status/123456/quotes` | Users who **quoted** the tweet |
| `x.com/username/status/123456/likes` | Users who **liked** the tweet |
| `x.com/search?q=keyword` | Users from **search results** |
| `x.com/i/lists/123456/members` | **Members** of an X list |

### Examples

To scrape everyone who quoted a specific tweet:
```
https://x.com/bonk/status/349434030493945/quotes
```

To scrape everyone who retweeted it:
```
https://x.com/bonk/status/349434030493945/retweets
```

To scrape everyone who commented:
```
https://x.com/bonk/status/349434030493945
```
