## Universal Scraper (Any Page)

The Universal Scraper works with any X URL — not just follower lists. Use it to scrape members from communities, participants in conversations, users in lists, or search results.

<Frame>
  <img src="/images/universal-scraper.png" alt="Universal Scraper page" />
</Frame>

### How to Use

<Steps>
  <Step title="Select token group">
    Choose a group from Token Manager for scraping.
  </Step>
  <Step title="Paste URLs">
    Enter one or more X URLs to scrape. These can be:
    - Community pages
    - List pages
    - Search result URLs
    - Any X page with user content
  </Step>
  <Step title="Start">
    Click **Start** to begin scraping.
  </Step>
  <Step title="Download">
    Download the results when complete.
  </Step>
</Steps>

### Common Use Cases

| Source | What you get |
|--------|-------------|
| Community URL | Community members and recent posters |
| List URL | All users in the list |
| Search URL | Users from search results |
| DexScreener export links | Members of token communities |

<Tip>
  Combine with DexScreener: export token community links from DexScreener → paste into Universal Scraper → get community member lists for DM campaigns.
</Tip>
