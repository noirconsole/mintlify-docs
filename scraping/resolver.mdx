## Resolver

The Resolver converts X usernames (screen names) into numeric user IDs. This is needed because DM targeting and some other operations require user IDs, not usernames.

<Frame>
  <img src="/images/resolver.png" alt="Resolver page" />
</Frame>

### How to Use

<Steps>
  <Step title="Select token group">
    Choose a group from Token Manager. These accounts perform the resolution lookups.
  </Step>
  <Step title="Load usernames">
    Upload a file with usernames (one per line) or paste them directly. The Resolver accepts large lists — hundreds of thousands of targets.
  </Step>
  <Step title="Start resolving">
    Click **Start**. The resolver processes usernames in bulk, converting each to a user ID.
  </Step>
  <Step title="Download results">
    Download the resolved user IDs. These are ready to use as DM targets.
  </Step>
</Steps>

### Typical Flow

```
Scraping (usernames) → Resolver (convert to IDs) → DM Targets (upload IDs)
```

<Info>
  Some usernames may fail to resolve — the account might be suspended, deactivated, or the username changed. Failed entries are reported separately.
</Info>

<Warning>
  Resolution speed depends on X's rate limits (~4 lookups/second per account). For large lists (100k+), use a bigger token group and proxies to speed things up.
</Warning>
