## Resolver

The Resolver converts between user IDs and usernames. Use it when a module requires a different format than what you have.

<Frame>
  <img src="/images/resolver.png" alt="Resolver page" />
</Frame>

### When You Need the Resolver

The scrapers output **usernames** by default. Most modules accept usernames directly, so you **don't always need the Resolver**.

| Module | Accepts | Resolver needed? |
|--------|---------|-----------------|
| **DM Bulk Sender** | Usernames and IDs | No |
| **Quote Tags** | Usernames | No |
| **Reply Quotes** | Usernames | No |
| **Wall Posts** | Usernames | No |
| **SMM Follow** | Usernames | No |
| **Image Tags** (Quoting) | IDs only | **Yes** (username → ID) |

The Resolver is mainly needed when you have **usernames** but need **IDs** (for Image Tags), or when you have **IDs** from an external source and need usernames.

### How to Use

<Steps>
  <Step title="Select token group">
    Choose a group from Token Manager. These accounts perform the resolution lookups.
  </Step>
  <Step title="Choose direction">
    Select whether you're converting IDs → usernames or usernames → IDs.
  </Step>
  <Step title="Load data">
    Upload a file or paste the data. The Resolver handles large lists — hundreds of thousands of entries.
  </Step>
  <Step title="Start resolving">
    Click **Start**. The resolver processes entries in bulk.
  </Step>
  <Step title="Download results">
    Download the converted data — ready to use in other modules.
  </Step>
</Steps>

<Info>
  Some entries may fail to resolve — the account might be suspended, deactivated, or changed. Failed entries are reported separately.
</Info>
