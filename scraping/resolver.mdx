## Resolver

The Resolver converts between user IDs and usernames. This is a necessary step because different modules require different formats.

<Frame>
  <img src="/images/resolver.png" alt="Resolver page" />
</Frame>

### Why You Need the Resolver

The Scraper outputs `.txt` files with **user IDs** (numeric). But not all modules accept IDs:

| Module | Accepts |
|--------|---------|
| **Bulk DM Sender** | IDs directly — no resolver needed |
| **Image Tags** (Quoting) | IDs directly — no resolver needed |
| **Quote Tags** | Usernames — **resolver needed** |
| **Reply Quotes** | Usernames — **resolver needed** |
| **Wall Posts** | Usernames — **resolver needed** |
| **SMM Follow** | Usernames — **resolver needed** |

So the typical flow is:

```
Scraper → IDs (.txt) → Resolver (ID → username) → Quoting / SMM / etc.
```

### How to Use

<Steps>
  <Step title="Select token group">
    Choose a group from Token Manager. These accounts perform the resolution lookups.
  </Step>
  <Step title="Load IDs or usernames">
    Upload a file or paste the data. The Resolver accepts large lists — hundreds of thousands of entries.
  </Step>
  <Step title="Start resolving">
    Click **Start**. The resolver processes entries in bulk.
  </Step>
  <Step title="Download results">
    Download the converted data — ready to use in other modules.
  </Step>
</Steps>

<Info>
  Some entries may fail to resolve — the account might be suspended, deactivated, or changed. Failed entries are reported separately.
</Info>
