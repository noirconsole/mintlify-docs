## Overview

The Scraping module lets you collect usernames from X. Use the scraped data for DM campaigns, quoting, reply quotes, or any other feature that requires a list of users.

### How Scraping Connects to Other Modules

Both scrapers output **usernames** by default. Most modules accept usernames directly:

```
Scraping → Usernames → Quote Tags, Reply Quotes, Wall Posts, SMM
Scraping → Usernames → DM Targets (accepts both usernames and IDs)
Scraping → Usernames → Resolver (username → ID) → Image Tags (requires IDs)
```

<Info>
  The scraper outputs `.txt` files with **usernames**. Most modules accept usernames directly — you only need the Resolver if a module requires numeric user IDs (e.g., Image Tags).
</Info>
