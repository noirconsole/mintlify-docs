## Overview

The Scraping module lets you collect usernames and user IDs from X. Use the scraped data for DM campaigns, quoting, reply quotes, or any other feature that requires a list of users.

### How Scraping Connects to Other Modules

Scraped data flows into multiple modules depending on what you need:

```
Scraping → IDs     → Bulk DM Sender (uses IDs directly)
Scraping → IDs     → Image Tags in Quoting (uses IDs directly)
Scraping → IDs     → Resolver (ID → username) → Quote Tags, Reply Quotes, Wall Posts, SMM
```

<Info>
  The scraper primarily outputs `.txt` files with user IDs. Some modules use IDs directly (Bulk DM, Image Tags), but most other modes need **usernames**. Use the Resolver to convert IDs to usernames when needed.
</Info>
