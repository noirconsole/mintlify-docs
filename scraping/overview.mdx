## Overview

The Scraping module lets you collect usernames from X. Use the scraped data for DM campaigns, quoting, reply quotes, or any other feature that requires a list of users.

### How Scraping Connects to Other Modules

The two scrapers output different formats:

- **Followers Scraper** → outputs **user IDs** (numeric)
- **Universal Scraper** → outputs **usernames**

```
Followers Scraper → IDs     → DM Targets (accepts IDs directly)
Followers Scraper → IDs     → Resolver (ID → username) → Quote Tags, Reply Quotes, Wall Posts, SMM
Universal Scraper → Usernames → Quote Tags, Reply Quotes, Wall Posts, SMM, DM Targets
```

<Info>
  Most quoting/SMM modules need **usernames**, while DM accepts both. If you scraped followers (IDs), use the **Resolver** to convert to usernames before using in Quoting or SMM.
</Info>
