## Overview

The Scraping module lets you build target lists for DM campaigns and other outreach. You can scrape followers from any X account, extract members from any X page, and resolve usernames into user IDs.

  <Card title="Any Page (Universal)" icon="globe" href="/scraping/universal-scraper">

  <Card title="Resolver" icon="magnifying-glass" href="/scraping/resolver">
    Convert usernames to user IDs for DM targeting.
  </Card>
</CardGroup>

### How Scraping Feeds Other Modules

Scraping is typically the second step in a campaign workflow:

```
DexScreener → find token community
            ↓
Scraping → scrape their followers/members
            ↓
Resolver → convert usernames to IDs
            ↓
DM → load targets and send messages
```

<Info>
  Scraped data is exported as downloadable files. You can then upload these files into the DM Targets page or use them for other modules.
</Info>
