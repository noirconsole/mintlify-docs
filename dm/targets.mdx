## DM Targets

The Targets page is where you manage the list of users who will receive your direct messages.

<Frame>
  <img src="/images/dm-targets.png" alt="DM Targets page" />
</Frame>

### Loading Targets

You can load targets in several ways:

- **Paste directly** — paste usernames or IDs into the text area (one per line)
- **Upload a file** — upload a `.txt` file with usernames or IDs (one per line)
- **From Scraping** — use exported files from the Scraping module

<Info>
  Targets accept both **usernames** (`@elonmusk` or `elonmusk`) and **numeric user IDs**. You can mix both formats in the same list. The sender resolves usernames to IDs automatically when needed.
</Info>

### Target Management

- View total target count and preview first entries
- Delete lists you no longer need
- Create multiple named lists for different campaigns

<Tip>
  For large campaigns (100k+ targets), upload via file rather than pasting. The file upload handles large lists efficiently.
</Tip>
