## Multichat

Multichat (formerly Inbox) aggregates replies from all your DM sender accounts into one unified view. Instead of checking each account separately, you see all conversations in one place.

<Frame>
  <img src="/images/dm-multichat.png" alt="DM Multichat page" />
</Frame>

### Features

- **Unified view** — replies from all DM accounts in one interface
- **Conversation threads** — see the full message history with each user
- **Multi-account** — switch between sender accounts to reply from the right one
- **Real-time updates** — new replies appear as they come in

### Using Multichat

Browse through conversations to find interested users. Multichat shows which of your sender accounts received each reply, so you can respond from the correct account.

<Tip>
  Check Multichat regularly after launching a campaign. Quick replies to interested users convert better than delayed responses.
</Tip>
