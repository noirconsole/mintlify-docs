## New Listings

This page shows a live stream of newly detected tokens from DexScreener. Data updates automatically every 30 seconds.

<Frame>
  <img src="/images/dex-listings.png" alt="DexScreener New Listings page" />
</Frame>

### What You See

The **Streaming** indicator at the top confirms the feed is active. Below it, a stats strip shows total tokens detected and currently displayed.

Each token row includes:

| Column | Description |
|--------|-------------|
| **Token** | Name and ticker symbol |
| **Age** | Time since listing (e.g., &lt;1m, 5m, 1h, 5d) |
| **Volume 24h** | Trading volume in the last 24 hours |
| **Market Cap** | Current market capitalization |
| **Chain** | Blockchain (SOL, ETH, BASE, BSC) — color-coded pill |
| **Socials** | Links to Twitter/X, Telegram, Discord, Website |

### Using Social Links

The social links column is key — clicking the **X (Twitter)** link takes you to the token's community account. You can then:
- Use that link in **Scraping → Followers** to scrape the community members
- Use it for research before deciding to engage

### Refresh

Data auto-refreshes every 30 seconds. Use the **Refresh** button for a manual update.

### Export

Click **Export** to download the current listing data for external use.
