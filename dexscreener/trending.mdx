## Trending Tokens

The Trending page shows top-performing tokens ranked by activity, filtered by blockchain and timeframe.

<Frame>
  <img src="/images/dex-trending.png" alt="DexScreener Trending page" />
</Frame>

### Filters

**Chain filter** — select which blockchain to view:
- **ALL** — all chains combined
- **SOL** — Solana
- **ETH** — Ethereum
- **BASE** — Base
- **BSC** — BNB Smart Chain

**Timeframe filter** — select the ranking period:
- **24h** — last 24 hours
- **6h** — last 6 hours
- **1h** — last hour

### Token Data

Each trending token shows:

| Column | Description |
|--------|-------------|
| **Rank** | Position in the trending list |
| **Token** | Name and ticker symbol |
| **Age** | Time since token creation |
| **Volume 24h** | Trading volume |
| **Market Cap** | Current market cap |
| **Price Change %** | Price movement for the selected timeframe |
| **Socials** | Twitter/X, Telegram, Discord, Website links |

### Auto-Refresh

Data updates every 30 seconds. The "updated X minutes ago" indicator shows the last refresh time. Click **Refresh** for immediate update.
