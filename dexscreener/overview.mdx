## Overview

DexScreener module connects to DexScreener.com and monitors cryptocurrency token activity in real-time. Use it to discover new tokens, track trending ones, and export links for use in other modules like Scraping.

### Typical Workflow

<Steps>
  <Step title="Configure filters">
    Set minimum market cap, liquidity, token age, and target chains in Settings.
  </Step>
  <Step title="Monitor new listings">
    Watch the live stream of new tokens that match your filters.
  </Step>
  <Step title="Check trending">
    Browse trending tokens across SOL, ETH, BASE, BSC by different timeframes.
  </Step>
  <Step title="Export">
    Export token links to use in Scraping (scrape community members) or for manual research.
  </Step>
</Steps>
