### How to Use

<Steps>
  <Step title="Get a list URL">
    Find the X list you want to track and copy its URL.
  </Step>
  <Step title="Add list">
    Paste the list URL into the tracker. The system starts polling it for new posts.
  </Step>
  <Step title="View feed">
    Switch to the feed view to see posts from all your tracked lists.
  </Step>
</Steps>

### Managing Lists

- Add multiple lists to track simultaneously
- Remove lists you no longer need
- Each list is polled automatically at regular intervals

<Info>
  Lists require an account token for API access. Make sure you have valid accounts in Token Manager.
</Info>
